# Parciales de años anteriores — SOLO segundo parcial

Sacados de `https://github.com/ucu-fit-dwym/historial-pruebas` (clonado en
`../../P1/historial-pruebas`). Cada carpeta contiene la plantilla original tal
cual la dieron (el `README.md` es el enunciado oficial, no se tocó) más la
resolución completa y un **`APUNTES-PARCIAL.md`** con lo importante, las
trampas y un plan de ataque.

| Carpeta | Tipo | Tema | Formato |
|---|---|---|---|
| `2026sem1-prueba2-vespertino/` | **Prueba real** (la más reciente) | Tablero tipo Trello | 6 ejercicios sobre plantilla con TODOs, json-server, CSS Modules, Context, Router |
| `2026sem1-simulacro-vespertino/` | Simulacro | BarApp (cuentas de un bar) | 6 puntos sobre plantilla con TODOs, json-server, Context, Router |
| `2025sem2-parcial2-matutino/` | Parcial real | Buscador de países con 3 filtros `<select>` | App desde casi cero, mock API dentro de Vite |
| `2025sem2-parcial2-vespertino/` | Parcial real | Países con 9 rutas (filtros por moneda/idioma/zona horaria) | Ídem; evalúa reutilizar componentes |
| `2025sem2-simulacro-matutino/` | Simulacro | Trivia: adivinar la bandera por el mapa | Azar, puntaje, Context |
| `2025sem2-simulacro-vespertino/` | Simulacro | Viaje por países fronterizos | Juego con estado global, dificultad, `/end` |

**Descartado a propósito:** `2025sem1/parcial2` (real y simulacro) son de
**React Native + Expo** (app móvil), no entran en el tema UT4-UT5 de este parcial.

## Orden de estudio recomendado

1. `2026sem1-prueba2-vespertino` — es el formato más probable (2026, 6 ejercicios, 5/6 = 100%).
2. `2026sem1-simulacro-vespertino` — mismo formato.
3. `2025sem2-parcial2-matutino` y `-vespertino` — para practicar router + fetch desde cero.
4. Los dos simulacros de 2025sem2 — lógica más rebuscada (azar, juego), buen entrenamiento de estado.
