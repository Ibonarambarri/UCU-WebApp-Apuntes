# Segunda prueba 2025 semestre 1

Segunda prueba del curso _Desarrollo Web y Mobile_ para el primer semestre de 2025. 

## Preparación para la prueba

Los estudiantes deben hacer un [_fork_ privado (🇪🇸 _bifurcación_)](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo) de [este repositorio](https://github.com/ucu-fit-dwym/parcial2-2025sem1), para luego clonarlo en sus computadoras. 

El contenido del repositorio incluye una plantilla para una aplicación móvil implementada con Javascript, React Native y Expo, disponible en la carpeta `mobile/`. En la carpeta `api/` se encuentran datos de prueba en formato JSON para ser utilizados con [`json-server`](https://github.com/typicode/json-server#readme).

La versión de NodeJS a utilizar está especificada en el archivo `.tool-version`. Si se tiene [asdf](https://asdf-vm.com/) instalado se puede ejecutar `asdf install` en la terminal para instalar la versión esperada y comenzar a usarla.

Las carpetas `api/` y `mobile/` tienen paquetes definidos con dependencias y _scripts_. Las dependencias pueden instalarse ejecutando el comando `npm i`, tanto en la raíz del repositorio como en cada carpeta.

## Realización de la prueba

Por favor diríjase al archivo `docs/PLANTEO.md` para comenzar con el ejercicio. Todo el código está a disposición del estudiante para ser ampliado, modificado e incluso borrado.

La entrega se realizará haciendo un [_pull request_ (🇪🇸 _solicitud de incorporación de cambios_)](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request) hacia el repositorio original.
