Ejercicio 02 — Función que pasa unos tests

Siempre es el segundo ejercicio, en las 6 pruebas. Pero no siempre del mismo tipo: desde 2026 es una función pura con tests automáticos que no podés modificar; en 2025sem2 era un sistema con estado que se verificaba mirando la salida de node.

Lo primero: abrí el test, no el enunciado ej02.test.js es la especificación real. Anotá cada assert como un requisito y esa lista es tu checklist. El segundo assert.ok te regala literalmente la validación de formato que tenés que escribir: copiala.

La decisión que más gente falla

Error vs. valor vacío: no es lo mismo Los tests distinguen dos situaciones que parecen la misma. Arrojá error solo cuando el contenedor o la forma de los elementos están mal (undefined, null, no es array, [{}]). Devolvé vacío cuando simplemente no hay coincidencias, o cuando falta el segundo argumento. Si le ponés un if (!capacidad) throw, rompés el test que pide modelosPorCapacidad(modelos) → [].

El esqueleto que resuelve el 90%

// 1. Validar el contenedor. Cubre undefined y null de una vez.
if (!Array.isArray(data)) {
  throw new TypeError("El primer argumento debe ser un array.");
}

const resultado = [];

for (const item of data) {
  // 2. Validar cada elemento. typeof null === "object", ojo.
  if (typeof item?.propA !== "string" || !Array.isArray(item?.propB)) {
    throw new TypeError("Formato inválido.");
  }
  // 3. Filtrar y quedarse con la parte que se pide.
  if (item.propB.includes(criterio)) {
    resultado.push(item.propA);
  }
}

return resultado;   // en el orden original: no ordenes nada

Antes de entregar

  • node ej02/ej02.test.js pasa — corrélo, no lo asumas
  • La función está exportada, con el nombre exacto del import del test
  • Devuelve array vacío para entrada vacía, no undefined
  • Arroja con null, undefined y con [{}]
  • No arroja cuando falta el segundo argumento
  • Respeta el orden original — deepEqual compara en orden
  • No mutaste el array de entrada (sort y reverse mutan)
  • Si usaste reduce, devolvés el acumulador siempre
  • No tocaste ej02.test.js ni el .json

Ejercicio 03 — DOM y API

El ejercicio grande. Desde 2026 junta las dos cosas que en 2025sem2 estaban separadas (el ej3 de DOM y el ej4 de API). Los cinco que tienen API son el mismo archivo con otros nombres: si te sabés el esqueleto, la mitad del ejercicio ya está escrita.

Lo primero: levantá el servidor cd ej03 && npm install && npm start → http://localhost:3000/. Y entrá a http://localhost:3000/<entidad> a ver el JSON: si eso responde, la API anda y cualquier problema es de tu código. Después escribí fetchJSON de memoria, antes que nada.

El molde de 2026, dos veces. El ciclo es: generar → mostrar → el usuario elige → POST → generar de nuevo → recargar el historial. El estado del elemento actual vive en una variable global (let currentCombo).

El día de la prueba

Sin internet y sin asistentes de IA. Podés usar todo lo que tengas en la computadora, así que esta carpeta entera te sirve: abrí los cuatro HTML en pestañas antes de empezar.

Los primeros 5 minutos

1Fork privado, clonar, abrir la carpeta.
2cd ej03 && npm install — arrancalo ya, que corra en segundo plano mientras leés.
3Leé los tres enunciados de corrido, sin escribir nada. Decidí en qué orden los vas a hacer.
4Abrí esta guía en las tres pestañas de ejercicios y fijate a qué parcial se parece cada uno.

El orden que conviene

ej02 → ej01 → ej03. El ej02 es el más corto y el único con una señal objetiva de «terminado» (los tests pasan): sacártelo de encima primero te deja tranquilo. El ej01 es predecible y se hace en un rato. El ej03 es el que más se puede alargar, así que dejale el bloque de tiempo más grande.

Si vas mal de tiempo: en el ej03, listar los datos ya vale puntos. Asegurate de que el GET y el dibujado funcionen antes de meterte con el POST.

Las cinco líneas que hay que saber de memoria

* { box-sizing: border-box; }                                    // ej01, arriba de todo

grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));     // ej01, la grilla

if (!Array.isArray(data)) throw new TypeError("...");            // ej02, validar

contenedor.replaceChildren(...items.map(itemElement));           // ej03, redibujar

await fetchJSON(url, { method: 'POST', body: JSON.stringify(x) });// ej03, guardar
