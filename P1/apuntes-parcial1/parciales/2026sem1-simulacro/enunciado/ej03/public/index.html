Ejercicio 03

Modificar el código de esta página para mostrar los colores definidos en la API. Cada color se muestra como un rectángulo con el fondo del color definido y el texto con el valor RGB.

rgb(200, 50, 50)
rgb(100, 250, 100)
rgb(80, 80, 150)

Este formulario debe permitir agregar nuevos colores, dados tres valores para rojo, verde y azul. Al enviar el formulario, el nuevo color se debe enviar a la API y la lista de colores de arriba se debe recargar.
