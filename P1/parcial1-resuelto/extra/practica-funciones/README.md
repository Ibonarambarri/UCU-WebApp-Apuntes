# Práctica — ejercicios estilo "ej02"

6 ejercicios nuevos con el mismo formato que los del parcial: función pura,
exportada, con tests automáticos que prueban caso vacío, casos normales, y que
tire error con datos inválidos.

```bash
node test.js                  # corre contra ejercicios.js  (los stubs, para resolver vos)
node test.js ./soluciones.js  # corre contra las soluciones  (para comparar)
```

Los tests se detienen en el primer fallo, igual que en la prueba. Resolvé de a
uno y volvé a correr.

**Consejo:** leé `test.js` antes de implementar. Los tests SON la consigna.
