# Extra — repaso para el Parcial 1

Material armado a partir de lo que **efectivamente se preguntó** en los 5
parciales/pruebas 1 que hay en `historial-pruebas` (2025sem2 mat/vesp +
simulacro, 2026sem1 prueba + simulacro).

| Archivo / carpeta | Para qué |
|---|---|
| `PATRONES.md` | qué se preguntó cada año y qué se repite. Leelo primero. |
| `CHECKLIST.md` | plan de ataque durante la prueba + errores que cuestan puntos |
| `snippets/` | código para copiar y pegar: fetch, CRUD, DOM, layouts |
| `practica-funciones/` | 6 ejercicios nuevos estilo "ej02" con tests automáticos + soluciones |
| `practica-api/` | app CRUD completa funcionando, para leer y para practicar |
| `galeria-layouts/` | los 4 layouts que salen siempre, resueltos y comentados |

Los archivos de `snippets/` son para **leer y copiar**, no para ejecutar
(usan variables que no existen). Todo lo demás corre **sin internet** (en la prueba no hay). `practica-api` ya tiene
`node_modules` instalado.
